DAILY TOOLS HUB — LOCAL TEST GUIDE

Files:
- index.html: the complete website

Easiest way to test:
1. Extract the ZIP file if you downloaded the ZIP.
2. Open the daily-tools-hub folder.
3. Double-click index.html. It should open in your browser.
4. Test the Image Compressor, Percentage/Discount Calculator, and Text Tools.
5. QR Code Generator needs an internet connection because its QR library loads from a CDN.

Recommended local server (optional):
- Install Visual Studio Code.
- Open the folder in VS Code.
- Install the "Live Server" extension.
- Right-click index.html and choose "Open with Live Server".

Notes:
- Image compression runs locally in the browser.
- The QR generator loads qrcode.js from cdnjs and needs internet.
- This is a static website; it does not need a backend or account.
- Before publishing, test each tool on both laptop and phone.
